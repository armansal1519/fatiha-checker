# Local font assets

These unmodified assets are served from this directory; the app makes no third-party font requests.

- **Vazirmatn Variable**: `fonts/webfonts/Vazirmatn[wght].woff2` from [rastikerdar/vazirmatn](https://github.com/rastikerdar/vazirmatn), commit `6e553e33489a8f9dfaccc76860a2e3f3c1e66de7`. Local filename: `Vazirmatn-Variable.woff2`. License: `Vazirmatn-OFL.txt` (SIL Open Font License 1.1).
- **Amiri Regular**: `fonts/Amiri-Regular.ttf` from [aliftype/amiri](https://github.com/aliftype/amiri), commit `6331fc82b0d20d9439a0792e21a9294ca015a93f`. License: `Amiri-OFL.txt` (SIL Open Font License 1.1).

Downloaded from `raw.githubusercontent.com` at the exact commits above. Vazirmatn is used for Persian interface text; Amiri is used for Arabic verses.
